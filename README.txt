BACKPACKSYSTEM 1.0.0 - PROYECTO FUENTE
Minecraft Java 26.3 / Paper 26.3 / Java 25

CONTENIDO
- src/: código fuente Java del plugin.
- resource-pack/: paquete de recursos para las mochilas y el módulo.
- build.gradle.kts y settings.gradle.kts: proyecto Gradle.
- INSTRUCCIONES.txt: guía completa de instalación, compilación y edición.

IMPORTANTE
Este paquete es el proyecto fuente y el paquete de recursos. No contiene todavía un
BackpackSystem.jar compilado. Paper 26.3 requiere Java 25 y este entorno de preparación
solo dispone de Java 21, por lo que no sería correcto entregarte un JAR sin compilar ni
probar. Las instrucciones explican cómo compilar el JAR en Windows con JDK 25.

El plugin debe probarse primero en una copia del mundo antes de instalarse en el mundo
principal del servidor. No se considera una versión probada en producción hasta validar
apertura, guardado, reinicio, mejora y textura dentro de un servidor Paper 26.3 real.
